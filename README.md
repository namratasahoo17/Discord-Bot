# Discord-Bot
This bot is made for our need in personal discord server where it checks , tracks and assigns badges according to the someone's achievements and learnings.
/register
    ↓
Create User

/submit
    ↓
Submit today's study
    ↓
Save StudySubmission
    ↓
Calculate streak
    ↓
Check & award badges

/profile
    ↓
Show:
  • Name
  • Discord ID
  • College ID
  • Member since
  • Current streak
  • Longest streak
  • Total study days
  • Badges
